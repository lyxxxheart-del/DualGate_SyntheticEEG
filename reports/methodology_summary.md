# 方法学纪要：用"空间协方差质量"对齐 CSP 下游任务

## Abstract / 核心结论

生成式运动想象（MI）脑电数据增强中，以生理指标（如 ERD）作为质量门槛存在系统性陷阱：**ERD 量化的是"时间能量对比"，而下游 CSP 分类器消费的是"空间协方差"——两者表征空间错位，导致筛选无效、甚至有害。** 本文提出双重门槛，与 CSP 共享同一表征空间：Gate 1 校验协方差结构有效性（拒噪），Gate 2 校验类别判别方向（拦截类间混淆样本）。在三种合成缺陷模型上，双重门槛一致恢复了下游分类性能。进一步用真实 SOTA 生成模型 DDF-Net（官方 UNetLidar DDPM，T=100）生成的 144 个样本做终局验证：其逐通道独立生成造成空间协方差结构崩塌（合成 cos-sim 0.368 vs 真实 0.996），原始样本令 CSP 精度从 0.8333 暴跌至 0.6667；双重门槛以 0% 漏网率（0/144）全拒，无损恢复至 Baseline 0.8333。

## Problem Statement

面向低真实数据场景，合成 MI-EEG 已被广泛用于数据增强。为了保证合成样本的质量，现有方法往往用生理学先验（事件相关去同步 ERD 的空间地形、起始潜伏期）来过滤合成样本。然而这种"生理合理性"门槛隐含一个未经检验的假设：**生理上合理的样本，就是分类器可利用的样本。** 本文证明该假设不成立，并定位其根源——门槛与下游任务使用不同的信号表征。

## The Disconnect（负结果呈现）

以"0 dB 白噪声破坏"（Mode 2）为例。ERD 门在源空间（eLORETA）或传感器空间（C3/C4）测量 mu 频段在任务期相对基线的功率下降，本质是**时间维度**的能量对比；而 CSP+LDA 依赖每试次的**空间协方差** `X Xᵀ`（`downstream._csp_filters` 直接以 `x @ x.T` 构建类协方差）。

错位带来三个直接后果：

1. **窗口跨零、无法强制方向。** 单试次 ERD 侧向化噪声过大，逐类 5%/95% 分位窗口仍横跨零点（源空间 `T_A_left=[-0.746,+0.622]`、`T_A_right=[-0.395,+0.759]`），"左右方向一致"无从谈起。
2. **检测不到协方差破坏。** 白噪声只把 ERD 幅度衰减约一半、并不消灭它，因此 ERD 门在 Mode 2 上保留了 ~74% 的噪声试次（106/144）。
3. **误删 + 有害。** 对时移（Mode 3，循环移位不改变协方差、对 CSP 无害）ERD 门仍约删除 ~20%；更严重的是，源空间 ERD 门在 Mode 2 全量真实数据下使准确率从 Unfiltered 的 0.792 **显著下降**到 0.722（`p=0.001`）——门槛不仅没用，删错试次时反而更差。

结论：ERD（无论哪个空间）与 CSP 协方差是两类正交的判据，不可能作为有效门槛。

## The Dual-Gate Solution（我们提出的解法）

解法是把门槛**迁移到 CSP 真正消费的表征**——传感器空间协方差，并与其共享同一套特征（22×22 协方差矩阵的上三角，253 维）。

### Gate 1：协方差有效性（Covariance validity）

对每个试次计算 `X Xᵀ`（与 CSP 完全一致），做 trace 归一化后取上三角；校准各类的协方差模板，以"试次与类模板的余弦相似度"落在类内 5%/95% 分位窗口为接受条件。该窗口**极紧**（`[0.990,0.999]`，类内相似度 `0.996±0.003`），能有效检测"空间结构崩塌"——白噪声破坏非对角元结构，使相似度跌出窗口。结果：Mode 2 上通过率 **0/144**，100% 拒噪。

### Gate 2：判别性投影（Discriminative projection）

余弦相似度对类模板打分测的是"像不像 EEG"，而非"属于哪一类"——类间混淆（左右混合）样本仍是合理协方差，故 Gate 1 无法拦截。为此，在真实协方差特征上训练 Fisher LDA，得判别方向 `w`；将试次投影为 `score = features · w`，要求其落入本类 5%/95% 分位窗口。真实左右分数**干净分离且中间留缝**（左 `[-99.011,-90.840]`、右 `[-88.905,-79.589]`，间隔 1.94），混合样本的投影 ≈ 中点 −89.9，恰好掉入这条"拒绝缝隙"被双杀。

## Results 总结

（10 种子，A01T 固定 108/36 留出分割；合成批量 144。）

| 缺陷模式 | ERD 门保留 | 协方差门保留 | 双重门保留 | F-Dual vs Unfiltered（p 值） |
|---|---|---|---|---|
| Mode 1 类别混淆 | 112/144 | 123/144 | **50/144** | 25% `p=0.015`，50% `p=0.016`，100% `p=0.370` |
| Mode 2 白噪声 | 106/144 | **0/144** | **0/144** | 50% `p=0.029`，100% `p=0.002` |
| Mode 3 时移 | 115/144 | 129/144 | 114/144 | 无系统性变化（100% `p=0.011`，略优） |

- **Mode 1**：判别门把通过率从 ~123 **腰斩至 ~50**；F-Dual 在 25%（0.750 vs 0.678）与 50%（0.800 vs 0.739）显著优于 Unfiltered，且逼近 Baseline（0.758/0.808）。
- **Mode 2**：双重门全拒噪声，F-Dual 精确回到 Baseline（0.833），显著优于 Unfiltered（0.778，`p=0.002`）。
- **Mode 3**：时移不改变协方差，门正确放行（~79.5%），未系统性误杀。

归一化稳健性：`raw` / `trace` / `corr` 三种协方差归一化在 Mode 2 上结果一致，说明决定因素是协方差信号本身，而非归一化方式。

## 终局验证：真实生成模型 DDF-Net（Stage-1 DDPM）

不重跑模型——T=100 即官方真实状态。在 RTX 3060 Ti 上真实训练 UNetLidar（38.93M 参数）100 epoch（loss 0.123 → 0.031），DDPM 采样 144 个合成试次（72/72 平衡）→ `[144, 22, 1126]`。

### 根因坐实：Covariance structure collapse

DDF-Net Stage-1 对 25 个通道**逐通道独立**建模（每通道一张 `166×600` 图像），生成后再拼回 1-D，因此跨通道空间协方差从未被建模。以类模板为基准（trace 归一化协方差上三角）实测：

- 真实 A01T 试次 cos-sim：**0.9963**（min 0.9857 / max 0.9993）。
- DDF-Net 合成试次 cos-sim：**0.3682**（min 0.3509 / max 0.3900）——不足 0.990 阈值下限的一半。

证据图：`reports/cos_sim_rejection_distribution.pdf`（分布对比）、`reports/real_vs_ddf_covariance.pdf`（协方差热力图：合成协方差近乎对角，非对角元流失）。

### 下游与门槛终局结果

| Condition | Accuracy | 合成样本 |
|---|---|---|
| Baseline | 0.8333 | — |
| Unfiltered | 0.6667 | 144/144 |
| Filtered-Cov | 0.8333 | 0/144 |
| Filtered-Dual | 0.8333 | 0/144 |

- 原始合成数据对 CSP **致命**：Unfiltered 0.6667，较 Baseline −0.17。
- 双重门槛 **0% 漏网**（0/144），下游性能**无损恢复**至 Baseline 0.8333。

### 结论

生成式 EEG 模型若不能在**联合通道分布**上建模，其数据不仅无用、而且有害；与下游共享表征的质量门槛是部署前的最后一道防线。

## Discussion（Limitation）

1. **天花板效应。** 100% 真实数据下 Mode 1 提升未达显著（`p=0.370`）：真实数据充足时混合样本的伤害本就有限，门槛的边际收益随之消失。
2. **边界漏网率。** 混合样本的判别分数服从约 `N(−89.9, 1.8)`，其分布横跨左右窗口分界（−90.84 与 −88.91），因此仍有 ~35% 的混合样本漏入窗口（双重门保留 50/144）。这是 5%/95% 分位门槛的固有代价；进一步收紧分位会误杀 Mode 3，故不采纳。
3. **单被试局限。** 校准基于 A01T 单被试、单一固定分割；门槛在跨被试/跨会话的泛化能力尚未验证，是后续工作的直接方向。

综上：**只有与下游分类器共享同一表征空间的判据，才能作为有效的数据质量门槛。** 本纪要构成后续顶刊论文的方法学 Base Draft。
